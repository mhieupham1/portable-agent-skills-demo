# Cross-platform evaluation rubric

The score checks whether an output demonstrates the shared procedure. It does
not require the same prose or the same number of questions/findings.

| Task | Observable criterion | Points |
| --- | --- | ---: |
| Requirements | Names an outcome and scope | 1 |
| Requirements | Separates open questions from assumptions | 1 |
| Requirements | Raises a material data/permission/delivery decision | 1 |
| Requirements | Gives observable acceptance criteria | 1 |
| Review | Identifies the write-before-authorization defect | 1 |
| Review | Includes a P0–P3 priority | 1 |
| Review | Includes a `task-service.js:line` reference | 1 |
| Review | Includes review coverage | 1 |

Passing threshold: all four criteria in the relevant task. A reviewer scores
transcripts using this rubric and records exact evidence rather than relying on
whether the response feels persuasive.
